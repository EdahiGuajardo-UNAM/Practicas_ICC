#  Practica 06

Dentro de esta práctica se encuentran 3 programas

---

## Estimación de Pi interactiva
Este programa estima el valor de pi utilizando la técina Monte Carlo, el usuario da un número de dardos y el programa aproxima el valor de pi con este número.


## Conversión de un número en base 10 a binario
Este programa  interactivo convierte a binario cualquier número entero positivo base 10.



## Cotizador interactivo
Este programa  interactivo cálcula  puede calcular los intereses simples o compuestos de un préstamo y su saldo final, incluye un menú interactivo con varias opciones.
