# Práctica 7: Introducción a la Programación Orientada a Objetos
**Introducción a las Ciencias de la Computación (Semestre 2027-1)**  
**Facultad de Ciencias, UNAM**

---



## Descripción del proyecto
Este proyecto tiene como objetivo realizar una práctica de los conceptos de la programación orientada a objetos, toma una simulación de un requerimiento de una empresa de paquetería para ilustrar como es posible usar los principios de las clases y objetos de java para crear código eficiente, organizado y entendible.

## Comandos para compilar, ejecutar y documentar



### 1. Compilación
```bash
javac -d bin PruebaPaqueteria.java

```

### 2. Ejecución
```bash
java -cp bin PruebaPaqueteria

```

### 3. Generación de documentación Javadoc
```bash
javadoc -d doc *.java

```
